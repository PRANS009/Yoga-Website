## Customer enquiry

Select a program, enter a name and email, and prepare an enquiry. Review the
message and choose Open email draft. Your email app opens a message addressed
to pransjangra99@gmail.com; you send it yourself. Copy enquiry is available
when the browser supports clipboard access. No customer data is saved by the
site. Only the completed timer count is stored in browser localStorage.

## Free hosting — GitHub Pages

1. Extract the downloadable website ZIP.
2. Create a public repository in your GitHub account.
3. Upload index.html, style.css, app.js and the assets folder to the repository
   root. Include downloads/prans-yoga-website.zip if you want the download link
   to work on the deployed website.
4. In Settings > Pages, choose Deploy from a branch, main and / (root), then Save.
5. Wait for deployment. Open the URL GitHub Pages shows, and confirm it works
   in a signed-out browser before submitting it.

## Free hosting — Netlify

1. Extract the website ZIP.
2. Sign in to Netlify and use its manual site deployment option.
3. Upload the extracted website folder containing index.html at its root.
4. When publishing completes, open the Netlify URL and confirm it works in a
   signed-out browser before submitting it.
